# core/dataset.py

**Purpose:** Joins observed snowfall labels with pre-computed weather feature CSVs and static resort metadata to produce the unified training dataset parquet.

**Inputs:**
- `data/processed/snowjapan_labels.csv` — daily observed snowfall for Japan resorts (from SnowJapan API via `collectors/snowjapan.py`)
- `data/processed/sh_labels.csv` — daily ERA5 snow_depth-change labels for SH resorts (from `build_sh_labels.py`)
- `data/processed/features_{resort_id}.csv` — one per resort, generated by `build_nh_features.py` or `build_sh_features.py`
- `regions.yaml` — static resort config (lat, lon, elevation, region, hemisphere)
- CLI args: `--output` (path override)

**Outputs:**
- `data/processed/training_dataset.parquet` — merged dataset with ~90 columns including labels, features, lag features, amplification factors

**Key parameters / constants:**
- `OUTLIER_THRESHOLD = 80.0` cm — rows with `overnight_snow_cm > 80` are dropped as data artifacts
- `AMP_CAP = 6.0` — per-resort NWP amplification is capped at 6× to prevent outliers (e.g. geto_kogen at 10.9× raw) from distorting inference
- Amplification is computed as `mean(observed) / mean(NWP_snowfall_24h)` over snowy days (`observed > 0.5cm` AND `NWP > 0.1cm`)

**Notes:**
- **`maritime_influence`** is now added as a static resort feature: `100.0 / (dist_coast_km + 10)`. Requires `dist_coast_km` in `regions.yaml` (defaults to 100 if absent).
- **`TRAINING_EXCLUDE`** blocklist:
  - `niseko_annupuri` — r=0.250 vs adjacent Hirafu; systematic under-reporting.
  - `sahoro` — r=0.149 on holdout; 190km inland, Pacific moisture pathway not captured.
  - AU/NZ resorts (`thredbo`, `perisher`, `falls_creek`, `cardrona`, `treble_cone`, `mt_hutt`, `coronet_peak`, `the_remarkables`, `whakapapa`) — ERA5 snow_depth labels average 3-5cm on snow days vs Japan's 15cm observed. The 3x scale mismatch dilutes Japan training signal and causes systematic underprediction. These resorts go through transfer calibration anyway so exclusion is correct.
  - All excluded resorts stay in `regions.yaml` for forecasting.
- `sh_labels.csv` now also includes NH resorts flagged `era5_labels: true` in `regions.yaml` (e.g. `whistler_blackcomb`). The "sh_labels" name is legacy; it covers all ERA5-sourced labels regardless of hemisphere.
- Lag features (`snow_depth_lag1`, `overnight_snow_lag1/2`, `overnight_snow_3d_sum`) are included in the parquet but **excluded from `FEATURE_COLS` in `core/train.py`** — unavailable at inference.
- `nwp_amplification` is stored as a constant column per resort; `core/train.py` recomputes it from training rows only to avoid test-label contamination.
