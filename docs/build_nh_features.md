# build_nh_features.py

**Purpose:** Generates daily weather feature CSVs for all Northern Hemisphere (Japan) resorts by applying `build_features(hemisphere="north")` to raw hourly weather data.

**Inputs:**
- `data/raw/weather/{resort_id}_*.csv` — raw hourly Open-Meteo weather, one file per NH resort
- `regions.yaml` — used to enumerate NH resorts (`hemisphere == "north"` or absent)
- CLI args: `--resort` (single resort override)

**Outputs:**
- `data/processed/features_{resort_id}.csv` — one daily feature CSV per NH resort (overwrites existing)

**Key parameters / constants:**
- Picks the largest (longest date range) weather CSV when multiple files exist for a resort

**Notes:**
- This script was created 2026-06-07 as a corrective — previously NH feature CSVs had been generated by an undocumented process outside version control. Now the pipeline is fully reproducible via `build_nh_features.py → build_sh_features.py → core/dataset.py → core/train.py → calibrate_transfer.py`.
- Must be re-run whenever `core/features.py` changes.
- The SH equivalent is `build_sh_features.py`.
